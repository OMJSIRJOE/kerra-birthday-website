# Kerra — Birthday Website

Separate project from `birthday-website` (Chidinma). Multi-page Next.js site for Kerra.

## Setup

```powershell
cd "C:\Users\omaka\OneDrive\Desktop\kerra-birthday-website"
npm install
npm run dev
```

Open http://localhost:3000

## Personalize

- **Copy & links:** `data/birthdayContent.js`
- **Images:** `public/images/` (see `public/images/README.txt`)

## Deploy

Deploy this folder to its own Vercel project (do not mix with the Chidinma site).
