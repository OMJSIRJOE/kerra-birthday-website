Image folders for Kerra's birthday site
======================================

public/images/us/

  - Letter portrait: letter.jpg (optional)
  - Memories: memory-1.jpg, memory-2.jpg, etc. (update memories.items in birthdayContent.js)

public/images/gifts/

  - watch.jpg — ONLY shown on /surprise

public/images/tribute/
